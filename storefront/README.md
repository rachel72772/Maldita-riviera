# Maldita Riviera storefront

Escaparate técnico de preapertura para **Mediterranean After Dark**.

## Estado seguro

- `noindex,nofollow` activo.
- Checkout y botones de compra desactivados.
- No hay formularios, analítica, publicidad ni píxeles.
- No se recogen datos personales ni de pago.
- Los datos fiscales y de contacto aparecen como campos pendientes.

## Catálogo provisional

- Conjunto de lunares.
- Cinco posiciones del pedido Maccolins.
- Los nombres, fotografías, tallas, unidades, composición y precios no deben publicarse hasta contrastarlos con la mercancía y la factura real.
- Paris Fashion Shops queda fuera de la selección comercial actual.
